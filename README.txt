AFAGS website (light version)
Upload everything in this folder to your web hosting (public_html). Keep the folders together:
  index.html          home page (about 0.4 MB) - opens fast on mobile data
  assets/             scripts and pictures
  guides/             the 5 registration guides (PDF) - downloaded only when a visitor opens one
  afags-portal.html   Member Portal - loaded only when someone clicks Member Login
  icons/, manifest.webmanifest, sw.js   app icon and offline support
To test on your computer: open index.html in Chrome or Edge.
With the AFAGS server (afags-server kit) the same files are already inside afags-server/public.
